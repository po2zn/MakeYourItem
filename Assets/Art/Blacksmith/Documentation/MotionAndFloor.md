# 자세·작업 동선 수정과 바닥판

## 수정한 원인

몸을 카메라 방향으로 고정하면서 작업 목표는 반대쪽에 두었던 점, 손목까지 무제한 CCD로 회전했던 점, 손잡이 위치로부터 모든 작업의 발 위치를 동일하게 계산했던 점을 수정했습니다.

ForgePoseSolver는 팔과 다리에 길이가 유지되는 두 관절 해법을 사용합니다. 팔꿈치 굽힘 방향을 좌우로 분리하고, 손바닥의 잡는 축을 도구 축에 맞춥니다. 망치는 머리 끝의 실제 타격면을 기준으로 준비-내려치기를 두 번 수행합니다. 다리는 무릎을 앞으로 굽히고 발목 목표를 바닥 높이에 맞춥니다. 현재 캐릭터에 손가락별 리그는 없으므로 개별 손가락 쥐기 애니메이션은 추가하지 않았습니다.

모루에서는 정면이 보이는 자세를 유지하고 화로에서는 작업 방향으로 몸도 돌립니다. 화로 가열에는 새로 만든 간단한 집게를 사용합니다. 물 냉각은 검을 기울여 들어 올리고 담글 때 세우므로 긴 검의 손잡이를 팔 길이 밖으로 올리지 않습니다. 공기 냉각의 흔들림도 도달 가능한 범위로 조정했습니다. 이동 중 물체를 손 위치에 유지합니다.

설비 렌더러의 실제 외곽으로 이동 경로를 계산해 화로·모루·양동이를 우회합니다. 화로에는 추가 여유 거리를 줍니다. 작업장 원점이 변경되는 고용 대장장이도 현재 위치로 환산한 장애물을 사용합니다. 프레임마다 경로를 생성하지 않고 작업 시작 시 계산합니다. 기존 제작 시간과 게임 자원 계산은 변경하지 않았습니다.

## 바닥판

- 사용자 제공 텍스처: `Assets/Art/Blacksmith/Interiror/바닥/중세 드워프 대장간 돌바닥 타일.png` (원본 보존, 별도 라이선스 정보 미제공).
- `Assets/Art/Blacksmith/Materials/WorkshopFloor.mat`: URP Lit, 원본 텍스처를 Base Map에 매핑.
- `Assets/Art/Blacksmith/Prefabs/WorkshopFloor.prefab`: 4.35×4.35m, 두께 0.12m, 윗면 y=0, BoxCollider, UV 매핑된 큐브 메시.
- 작업장 간격 4.5m보다 작아 인접 작업장의 바닥판이 겹치지 않습니다. Resources 카탈로그로 실제 게임에 자동 배치됩니다.
- `SmithTongs.prefab`, `TongsIron.mat`: 직접 만든 단순 집게. Unity 내장 큐브 메시를 사용하는 저장된 Prefab입니다.

## 검증

SmithMotionChecks: 초기화 후 작업장을 30m 이동시킨 환경에서 적재→가열→망치질→물 냉각→재가열→망치질→공기 냉각을 연속 실행했습니다. 손 도달 오차/망치 타격점 오차 2.5cm 이내, 손이 몸 앞에 위치, 발목이 바닥보다 10cm 이상, 화로 실제 외곽에서 몸 중심 최소 28cm 거리를 조건으로 검사했습니다. MotionChecks.txt에 측정값과 Motion_*.png에 실제 렌더를 저장했습니다. 발목 높이는 발바닥 높이가 아닙니다.

별도 물·얼음·공기 냉각 검사에서 침수·인출·증기·발광 해제를 확인했습니다. 새 동작은 현재 Copperbeard 체형에 맞춘 절차적 애니메이션이며 모션 캡처/새 FBX 애니메이션 클립은 아닙니다. 바닥판과 동작은 원본 모델·기존 장면을 덮어쓰지 않고 연결했습니다.
