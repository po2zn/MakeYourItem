# 하루와 내부 시각

- 게임 시작: Day 1, 08:00. 게임을 다시 시작하면 초기화됩니다. 디스크 저장은 아직 없습니다.
- 기본 하루 길이: 실제 600초. ForgeDayCycle의 Inspector에서 조절합니다.
- 내부 숫자: ForgeMvp.DayCycle.CurrentHour (double, 0 이상 24 미만). 예: 13.5는 13:30입니다.
- 날짜: ForgeMvp.DayCycle.Day (int, 1부터 시작).
- ForgeMvp.DayCycle.Clock.DayChanged 이벤트는 새 날짜를 전달합니다. 긴 프레임에 여러 날을 넘기면 최종 날짜를 한 번 알립니다.
- 시계는 Time.deltaTime으로 진행하므로 timeScale이 0이면 멈춥니다. 제작 실행 여부와 관계없이 흐릅니다.
- 24:00에 시각을 0시로 순환하고 날짜를 증가시킵니다. 남은 시간도 보존합니다.
- 시작 및 날짜 변경 시 상단 Day N: 0.8초 페이드 인, 1.8초 유지, 1.4초 페이드 아웃.
- 06:00 일출, 18:00 일몰. 태양과 달의 방향 및 강도, 배경과 환경광이 시간에 따라 변합니다.
- 기존 방향광은 실행 중 대체하고 컴포넌트 파괴 시 복구합니다. 작업대 등 다른 조명은 유지합니다.
- 도면 함수: 12()는 낮에 1, 밤에 0. 24()는 밤에 1, 낮에 0. 낮의 범위는 06:00 이상 18:00 미만입니다.
- 24(60)은 자정부터 지난 정수 분(0~1439)을 반환합니다. 초는 버리고 자정에는 0으로 돌아갑니다.
- 12()와 24() 계열은 테크 트리에서 각각 20G로 해금합니다. 24(60)은 24() 구매에 포함되며 호출 자체는 골드/재료를 소비하지 않습니다.
- 정수 반환값이므로 조건문에서는 12() == 1 또는 24() == 1로 비교합니다.
- 전체/한 줄 실행 및 import 안에서도 호출 순간의 살아 있는 게임 시계를 조회합니다. C# 독립 평가에서는 clockHour 콜백으로 시계를 주입할 수 있으며 생략하면 08:00으로 평가합니다.

검증: Tools > MakeYourItem > Validate Day Cycle. 자정 경계, 여러 날 진행, 정지, 하루 길이, 잘못된 입력, 페이드 구간을 검사합니다.
