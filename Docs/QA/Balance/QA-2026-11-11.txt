[가정 — 측정값과 구별]
입문: 튜토리얼/첫 학습 20분, 연구당 읽기 120초, 도면 변경 240초, 제작 묶음 조작 12초, 병렬 활용 최대 2명.
경험: 10분 / 60초 / 120초 / 5초 / 최대 4명.
숙련: 4분 / 20초 / 45초 / 1초 / 최대 16명.
자동판매 후 조작 시간은 절반. 상점 조작은 10/30/100개마다 20/10/4초로 가정합니다. 재료는 부족분을 실제 가격으로 구매하되, 일괄 재고 구매로 미리 묶이는 자금은 모델링하지 않았습니다.
진행 중 충분한 운전자금을 남기고 연구하며, 부족하면 기본 철 검날로 복구합니다. 각 단계에서 해금된 후보 코드를 실제 해석기로 검증한 뒤 수익 효율이 높은 후보를 선택합니다. 입문자는 봉인·공명·마력 최적화 조합을 사용하지 않습니다. 따라서 입문 모델도 안내서 지원을 받아 올바른 코드를 발견한다는 낙관적 가정입니다. 실제 초보자의 문법 오류 빈도·중도 포기·이해도는 측정하지 않았습니다.
생산 시간은 공정 duration와 60fps 프레임 전환 근사치입니다. 병렬은 동일 도면의 묶음 작업으로 모델링하며, 실제 프레임별 공유 자원 경합은 근사합니다. 공용 재료·골드 잔고를 검사하고 실제 ForgeShop으로 판매합니다.
ForgeBlacksmiths의 게임 날짜, 호감도 감소, 대성공·파괴 난수 규칙을 반영했습니다. 선물·거대한 룬으로 최적화한 정책은 포함하지 않았습니다. 시드 5개의 범위는 인간 플레이 시간의 신뢰구간이 아닙니다.
CSV의 engine/learning/interaction 합계는 일반 연구 전체 완료까지이며, ending_seconds와 다릅니다.

[발견 및 수정]
B01. 첫 연구 150G, 주요 공정 20~50G로 판매 몇 번만으로 연속 구매 가능. 연구·가속 가격을 재설정했습니다. root 1200G, 충전 6000G, 룬 30000G, 스피드 최종 180000G. 전체 변경표는 price-changes.csv.
B02. 재료비와 시간을 포함하면 은도금·충전·마력 단조·용뼈·공명이 기본 검 반복보다 불리. 연마 자체 +25G를 추가하고 고급 공정 보상을 높였습니다. rewards.csv는 1배속, 반복 구매 재료비 차감, 조작/대장장이 운 제외의 비교입니다.
B03. 보호+저주로 안전한 10배 판매가 가능. 저주를 3배로 조정하고 후반 연구 비용을 180000G로 조정했습니다. 보호 없는 파괴 확률 25%는 유지됩니다.
B04. 고급 행운 검도 다이아 1개여서 저급 반복이 유리. 기본 1개, 별무늬 별철 +1개, 명작 조건 충족 +1개로 최대 3개를 지급합니다. 균열·미완성·행운 미적용에는 지급하지 않습니다.
B05. 고용 비용을 100/250/600/1500/3500 다이아로 조정했습니다. 고급 검 다이아 보상과 함께 재검증했습니다.
B06. 첫 비용 상향안에서 입문자 마지막 의뢰 반복 구간이 과도하게 길어졌습니다. 별철 공급 8000G, 용뼈 공급 25000G, 정제 50000G, 마지막 의뢰 90000G로 보정했습니다. 단순히 총 시간을 늘리기 위한 가격 상향은 되돌렸습니다.
B07. 안내서에 별칭 설명과 본문 설명이 반복되고, 새 내용 알림이 열린 책에 겹침. 동일 설명을 한 번만 표시하고 책을 읽는 동안 외부 알림을 숨깁니다. 책 안의 새 내용 버튼은 유지됩니다.

[아직 남는 설계 위험]
숙련자의 스피드 3 우선 경로는 약 42분에 엔딩에 도달합니다. 이것은 조사한 경로 중 최단이며 전역 최단 공략 증명은 아닙니다. 연구 35개 전부가 엔딩의 필수 조건은 아닙니다.
초기에 제안한 2~3시간/3~5시간/5~8시간은 확정된 사용자 목표가 아니며, 이번 결과는 그 시간대에 도달하지 않았습니다. 그 시간대를 수치만으로 강제하면 입문자의 반복 작업 부담이 다시 커집니다. 이번 변경을 '완벽한 재미/최종 밸런스'로 확정할 근거는 없습니다.
사람의 읽기·조작 가정을 0.5배/1.5배로 바꾼 sensitivity.csv를 참고하세요. 추가 콘텐츠 없이 숙련도별 시간 차이를 없애기 어렵습니다. 실제 세 모집군의 첫 플레이로 이해도, 반복 피로, 각 기술 사용 여부를 확인해야 합니다.

[검증]
구매 DAG·선행 조건·중복 결제·재고 범위·가속 단계·기존 저장 노드 호환성 통과. 경제 14개/확장 공정 12개 회귀 검사 통과. 신형 보상·저주 확률·다이아 품질 단계 검사 통과. 실제 자원 구매를 거치는 순수 캠페인 경로도 엔딩에 도달했습니다.
별도 Unity 플레이 모드에서는 테스트용 후반 자금을 넣고 실제 구매/실행 코루틴/자동판매/엔딩 화면을 검증했습니다. 1179G 판매, 다이아 3개, 5배속 최종 제작 약 3.1초를 확인했습니다. 이 후반 스모크 테스트의 지급 자금이나 벽시계 시간은 신작 시작~엔딩 추정치에 사용하지 않았습니다. 사용자 저장 슬롯에는 테스트 상태를 저장하지 않았습니다.
800x600, 1280x720, 1920x1080, 3840x2160 연구 UI 및 안내서 텍스트 영역 검사, 숫자·영문 154개 페이지와 최소 안내서/코드창 크기 검사. 실제 화면 캡처는 guide-*.png에 기록합니다. 긴 내용은 스크롤 영역에 남아 있습니다.
플레이 도중 스크립트 재컴파일이 걸린 테스트 세션에서 UI 캐시 KeyNotFoundException이 한 번 발생했습니다. 깨끗한 플레이 재시작 후 본 검증을 수행했습니다. 플레이 중 코드 교체의 복구는 이번 경제 밸런스 검증 범위에 포함하지 않았습니다.
