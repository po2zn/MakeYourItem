# 자유 제작 실행 규칙

2026-11-09 변경. 이전 문서의 제출 필수·미완성품 오류·공정 호출 위치 제한보다 이 문서를 우선합니다.

- 문법과 함수 인자 규칙을 지키면 제출 없이 계산·공정을 실행합니다. 함수 1~4는 여전히 인자가 필요합니다.
- `1(1)` 단독 호출, `2(1(1), 7)` 중첩 호출, 사용자 함수의 반환식·조건식 속 공정도 실행됩니다. 평가 순서는 왼쪽에서 오른쪽이며 단락 평가로 건너뛴 호출은 실행하지 않습니다.
- 2~4는 작업물을 변경하고 None을 반환합니다. 반환값을 대입하거나 출력할 수 있습니다.
- 열 6 미만 타격도 실행됩니다. 성형 효과만 없으며 이전 성형 상태는 유지합니다.
- `!`는 현재 결과물을 제출하고 실행을 끝냅니다. 작업물 또는 등록된 재료 번호를 받습니다. 기존의 최상위/조건문 위치 규칙은 유지합니다.
- `res = 1` 다음 줄의 `!res`는 철 재고 1개를 소비하고 가공비 0G, 판매가 0G인 원재료를 제출합니다. 단순 숫자 대입만으로는 재고를 소비하지 않습니다. 재료 번호 제출 때 실제 재고를 확인합니다.
- 성형되었고 열이 0인 철 검날만 28G입니다. 뜨거운 검날·미성형·다른 재료는 0G로 등록됩니다. 0G 판매도 해당 상품을 한 번만 제거합니다.
- 1번 공정은 기존처럼 10G와 재료 1개, 가열은 2G입니다. 재료 부족·잘못된 인자·실행 한도 오류에서는 이전 성공 공정만 남습니다.
- 제출이 없는 작업물은 현재 실행에서만 가공합니다. 다음 실행으로 변수나 작업물을 이어 넘기지는 않습니다.

## 대장장이 동작

ForgeCraftMotion은 공정 실행 기록을 순서대로 재생합니다. 현재 캐릭터는 기본 도형으로 만든 임시 대장장이입니다. 재료 올리기, 화로 이동/가열, 작업대 타격, 공기 냉각대 이동/냉각을 수행합니다. 여러 작업물은 개별 ID로 구분하며 열·성형 상태는 각 공정 당시의 스냅샷을 사용합니다. 출력과 계산은 물리 동작을 추가하지 않고, 실패하거나 실행되지 않은 공정도 재생하지 않습니다. 시험 실행은 실제 재고·상품·동작을 변경하지 않습니다.

## 검증

Tools > MakeYourItem > Validate Free Forge: 원재료 제출/재고, 제출 없는 실행, 중첩 호출, 조건/반환식 공정, 단락 평가, None 반환, 저온 타격, 작업물 ID, 오류 이전 기록, 시험/실제 장부 일치를 검사합니다. 기존 언어·판매·출력·재료·가이드 검사도 새 규칙에 맞춰 유지합니다.

검증 결과: Unity 6000.4.5f1 참조 컴파일 및 신규 12개·기존 회귀 검사 통과. 별도 테스트 프로젝트의 Unity Play Mode에서 6개 공정 동작, 대장장이 이동·망치 회전, 두 작업물 분리와 성형 상태, 다음 실행 시 작업물 정리를 확인했습니다. 헤드리스 검사이므로 실제 화면에서 보이는 배치·미술 품질은 시각 검증하지 않았습니다. 로그: Temp/FreeForgeChecks.txt, Temp/FreeForgeMotion.txt.
